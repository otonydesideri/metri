# Contexto: Notas

## Termos

**Nota** · `Note`
Texto que o autor guarda para reencontrar depois, com título e corpo.
_Evitar:_ Anotação, Lembrete, Memo, Post

**Autor** · `Author`
Quem escreve e lê as notas. Nesta versão o app tem um autor só, sem conta.
_Evitar:_ Usuário, Dono, User, Owner

## Relações

Uma `Note` não guarda autor nesta versão: todas as notas são do único `Author`.

## Ambiguidades resolvidas

"Lembrete" sugere data e aviso, que uma `Note` não tem: são coisas diferentes.
