# PRODUCT.md Format

`docs/PRODUCT.md` holds who the product is for, which problem it solves, the expected outcome, the scope and what is out of scope. Prose in Portuguese; the section titles are fixed.

```md
# <Produto>

## Para quem e qual problema

## Resultado esperado

## Escopo

## Fora de escopo
```

It holds no domain language (that goes to `docs/CONTEXT.md`), no feature list (that goes to `.metri/specs/`) and no implementation detail.
