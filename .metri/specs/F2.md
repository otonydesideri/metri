# F2 · Harness Claude Code e papéis

## Problema

O Metri não tem loop de agente próprio. Ele precisa do Claude Code pronto na máquina, com o login que a pessoa já fez, e precisa saber que modelo cada papel usa. Uma chave de API esquecida no ambiente da máquina desvia a cobrança do plano da conta Claude para a API sem ninguém perceber.

## Solução

Na tela de Harnesses, o humano vê se o Claude Code está pronto: o binário em uso (o que vem com o Agent SDK ou outro caminho configurado), a versão e o resultado do último teste, que abre uma sessão curta do harness. O Metri avisa quando a versão difere da suportada e quando há uma chave de API no ambiente. Quem prefere a chave de API entra com ela no próprio Claude Code, e a tela mostra qual modo está ativo, conta Claude ou API. Na configuração do projeto, o humano escolhe o modelo de cada papel, e na tela do ticket pode trocar o modelo antes de despachar.

## Casos de uso

- UC2.1 · Conferir o Claude Code
- UC2.2 · Escolher o modelo de cada papel e de cada ticket
- UC2.3 · Usar o Claude Code com chave de API
