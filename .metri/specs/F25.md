# F25 · Windows nativo

## Problema

Quem trabalha no Windows sem o WSL fica sem o Metri. O Windows muda o que os agentes conseguem garantir: o Claude Code não tem sandbox ali, o sandbox do Codex depende de uma instalação com administrador, e caminhos longos, processos órfãos e arquivos travados quebram worktrees e arquivamento.

## Solução

O Metri roda no Windows 10 1809 ou mais novo, em x64 e ARM64, com o Claude Code e o Codex. Na partida, ele confere o que o Windows precisa e diz o que falta. Os Workspaces ficam numa raiz curta, com nomes curtos, e arquivar um Workspace encerra a árvore inteira de processos e apaga a pasta sem atravessar nada fora dela. Como o Claude Code não tem sandbox no Windows nativo, a Policy dele vale por aprovação e allowlist; o Metri diz isso na tela, e o humano aceita uma vez por projeto. O CI do repositório do Metri ganha o job de Windows.

## Casos de uso

- UC25.1 · Rodar o Metri no Windows nativo
- UC25.2 · Rodar o Claude Code no Windows sem sandbox
