# F24 · Release

## Problema

Levar entregas para produção tem passos que só o humano faz (credencial, painel de terceiro, deploy), e é aí que eles são esquecidos.

## Solução

Um ticket de release roda depois que as slices liberadas estão feitas. Cada passo que só o humano pode fazer aparece como um portão de passo humano, um por vez. O release termina com a tag de versão e confirma que a versão que responde é a lançada.
