# F22 · Ver o conhecimento

## Problema

O conhecimento do projeto (produto, specs, arquitetura, regras, decisões) mora no git, e lê-lo hoje significa abrir o editor.

## Solução

Na barra lateral do projeto, o humano vê a lista de arquivos de conhecimento, com busca por título, e abre cada um renderizado, da branch padrão, com o portão que o aprovou. A tela só mostra; a edição continua pelo git ou pelas etapas.
