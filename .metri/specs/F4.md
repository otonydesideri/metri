# F4 · Moldar

## Problema

Uma iniciativa começa vaga, e os documentos que a definem (produto, linguagem, design, specs, decisões) nascem de uma entrevista longa com o humano. Feita à mão com um agente, essa entrevista some quando a conversa acaba, e nada impede o agente de escrever fora do lugar ou de criar trabalho antes de a direção ser aprovada.

## Solução

Uma iniciativa abre um Run de Moldar num Workspace próprio, `plan/<n>`. O agente pergunta em rodadas, e o Run espera a resposta sem gastar tokens. Ele escreve PRODUCT, CONTEXT, DESIGN, ADRs e as specs no git do Workspace, e cria os UCs em rascunho pelo Metri. Um painel ao lado da conversa mostra os arquivos do `plan/<n>` mudando e as propostas feitas. Antes do portão de direção, o crítico sem contexto lê o que foi escrito. O portão mostra os três blocos e o diff dos documentos.

## Notas

- Abordagem descartada: o Run de Moldar sem o painel dos arquivos. O humano responderia às perguntas sem ver os documentos nascendo.
- Abordagem descartada: o Moldar continuar no Claude Code, à mão, com o Metri só recebendo a branch. O primeiro marco não cumpriria o próprio critério de saída, em que as slices seguintes são planejadas dentro do Metri.
