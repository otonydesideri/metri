# F17 · Exportação

## Problema

O plano e o histórico de execução moram no banco local. Quem quer guardar o plano no git, ou levar um Run para analisar fora do Metri, não tem como.

## Solução

O humano exporta o plano para `.metri/export/`, em Markdown, no formato do método, e o Metri nunca lê de volta o que exportou. Um Run pode ser exportado como arquivo, com os eventos, os eventos brutos do harness, o uso e os checks.
