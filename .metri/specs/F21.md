# F21 · Começar o método num repositório

## Problema

Uma pessoa de fora chega com uma pasta vazia ou com um repositório que já tem código e ainda não usa o método. Hoje ela precisa rodar o `metri init` à mão e mapear o código sozinho.

## Solução

Numa pasta vazia com git, o Metri cria o projeto com o starter e confere com o `metri verify`. Num repositório com código, nada é copiado: o mapeamento fica pendente, e o Look across começa por um Run somente leitura que propõe as slices já construídas e as regras do projeto. O projeto novo traz o workflow de CI com Linux, macOS e Windows.

## Casos de uso

- UC21.1 · Criar projeto numa pasta vazia
- UC21.2 · Mapear um repositório com código
