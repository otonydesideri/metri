# UC24.1 · Fazer um release

Como humano, quero que o release me peça cada passo manual na ordem, para não esquecer nenhum.

## Regras de negócio

- BR71: O release só roda com as slices liberadas feitas, e cada passo que só o humano faz é um portão de passo humano, um por vez.

## Critérios

- [ ] Com um ticket de release e as slices dele feitas, cada passo humano aparece como portão, um por vez, e a slice só fica liberada depois do último.
- [ ] O release termina com a tag de versão.
- [ ] O teste de fumaça confirma que a versão que responde é a lançada, não só que o app responde.
