# UC25.1 · Rodar o Metri no Windows nativo

Como humano, quero usar o Metri no Windows sem o WSL, para trabalhar na máquina que eu já tenho.

## Regras de negócio

- BR72: Nenhum processo do Metri ou de um Run inicia com pasta de trabalho acima de 260 caracteres.
- BR73: Arquivar um Workspace encerra a árvore inteira de processos dele antes de apagar a pasta, e a remoção nunca atravessa uma junction.

## Critérios

- [ ] No Windows 10 1809 ou mais novo, em x64 ou ARM64, o Metri sobe, abre um projeto e conclui um Run de builder com o Goal atingido.
- [ ] Na partida, o Metri confere o Node, o Git for Windows 2.54 ou mais novo, o `core.longpaths` e o `LongPathsEnabled`, e diz o que falta.
- [ ] Os Workspaces ficam numa raiz curta, com nomes curtos, e um projeto com dependências profundas instala e roda os testes sem erro de caminho longo.
- [ ] Arquivar um Workspace com servidor e testes rodando encerra todos os processos, fecha o banco e apaga a pasta, tentando de novo enquanto houver arquivo travado.
- [ ] Arquivar um Workspace com junctions do pnpm dentro não apaga nada fora dele.
- [ ] Os testes de contrato dos drivers passam no Windows.
- [ ] Num push ou pull request no repositório do Metri, o CI roda lint, typecheck, testes e `metri verify` também em Windows.
