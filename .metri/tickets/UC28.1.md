# UC28.1 · Rodar os guardrails no CI em macOS

Como humano, quero que os guardrails rodem também em macOS no CI, para que um problema só do macOS apareça antes de chegar a quem usa.

## Regras de negócio


## Critérios

- [ ] Num push ou pull request no repositório do Metri, o CI roda lint, typecheck, testes e `metri verify` também em macOS.
- [ ] Um teste que falha só no macOS deixa o CI vermelho, com o job de macOS apontado.
