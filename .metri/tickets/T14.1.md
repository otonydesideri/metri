# T14.1 · Método do repositório pelo link do workspace

## O que entrega

Depois do aceite do tracer, o processo de construção usa `packages/method` pelo link do workspace, e cada Run grava a versão do método com que rodou (ADR-0001).

## Critérios

- [ ] A raiz instala o método pelo link do workspace, e o `pnpm verify` passa.
- [ ] Cada Run grava a versão do método e o commit de `packages/method` com que abriu.
- [ ] Uma mudança em `packages/method` vale só para os Runs abertos depois do merge dela na branch padrão.
