# UC21.1 · Criar projeto numa pasta vazia

Como humano, quero criar um projeto do método numa pasta vazia, para começar com a fundação pronta e verde.

## Regras de negócio

- BR69: Numa pasta sem código, o `metri init` entrega o starter; uma pasta sem git é recusada.

## Critérios

- [ ] Numa pasta vazia com git, criar o projeto copia o starter, o `metri verify` fecha verde, e o projeto aparece na lista.
- [ ] Com o `metri verify` vermelho na criação, a tela mostra a saída, e o projeto não é criado.
- [ ] O projeto novo traz o workflow de CI com Linux, macOS e Windows.
