# UC10.2 · Ver o app rodando

Como humano, quero ver o app de um Workspace, de uma slice em aceite ou da branch padrão rodando, para julgar a tela sem mexer no meu checkout.

## Regras de negócio

- BR19: O Preview roda o app do Workspace pelo run dos scripts do projeto, numa porta de Preview do Workspace, só em `127.0.0.1`.
- BR20: O Preview da branch padrão usa um Workspace próprio, sem Run e sem escrita, arquivado ao fechar. O Preview nunca usa o checkout principal do humano.

## Critérios

- [ ] Com um Workspace pronto, o Preview sobe o app e o mostra em desktop e em mobile; se o app não sobe ou a porta está ocupada, o Preview mostra a saída do run e o motivo.
- [ ] Um app que recusa ser embutido (`X-Frame-Options` ou `frame-ancestors`) abre em nova aba; quem confere os cabeçalhos é o servidor do Metri, porque a página não fica sabendo que o iframe foi recusado.
- [ ] Com o Workspace arquivado, o Preview aparece indisponível, com o motivo.
- [ ] O Preview da branch padrão sobe o app num Workspace próprio, que é arquivado ao fechar, e o `git status` do checkout principal não muda.
- [ ] Sem o run nos scripts do projeto, o Preview diz o que falta.

## Notas

- A política de conteúdo do Metri precisa liberar em `frame-src` as portas de Preview.
