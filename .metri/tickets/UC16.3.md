# UC16.3 · Pagar por assento

Como humano, quero pagar o Metri por assento, com nota fiscal, para pagar pelo que a organização usa.

## Regras de negócio

- BR65: A cobrança é por assento, por mês, com período de teste.

## Critérios

- [ ] O `owner` assina um plano com N assentos, e a licença passa a valer para N membros.
- [ ] Ao aumentar os assentos no meio do ciclo, a diferença é cobrada de forma proporcional.
- [ ] Cada pagamento confirmado gera a nota fiscal.
