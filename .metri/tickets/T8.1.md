# T8.1 · Ferramentas do Metri para os agentes

## O que entrega

O endpoint MCP do servidor local, com um token por Run e as ferramentas filtradas pelo papel: `get_work`, `rules_for` e `report` nesta slice. A regra do projeto, com um arquivo só que registra ferramentas, e o hook que recusa ao subagente as ferramentas de escrita (ADR-0014).

## Critérios

- [ ] A regra do projeto existe, com o exemplo canônico e o check que acusa ferramenta registrada fora do arquivo de registro.
- [ ] Cada Run recebe um token próprio, guardado só como hash e revogado quando o Run termina; uma chamada com o token de um Run encerrado recebe 401.
- [ ] A lista de ferramentas devolve só as do papel do Run, e uma chamada com `Origin` ou com `Host` diferente do esperado é recusada.
- [ ] `get_work` devolve o ticket, a slice, o Goal e as regras do ticket; `report` grava o resultado estruturado e responde na hora.
- [ ] Um subagente que chama `report`, `propose`, `ask_human` ou `add_note` é recusado, e o evento fica no Run pai com o id do subagente (ADR-0004).
