# UC13.2 · Ver o mapa de Runs

Como humano, quero ver num mapa quem está trabalhando em quê e como os Runs se ligam, para achar logo onde algo parou.

## Critérios

- [ ] Tela: com Runs de uma slice, o mapa mostra o Coordinator no topo, um ramo por ticket, os Runs de cada ticket em sequência, os revisores e a integração, com o estado de cada um em texto.
- [ ] Os subagentes aparecem como filhos do Run que os disparou.
- [ ] Tela: o modo lado a lado mostra até três Runs ativos, cada um com a conversa ao vivo.
- [ ] Um Run travado mostra o aviso no próprio nó, e o estado dele não muda sozinho.
