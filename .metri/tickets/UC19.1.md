# UC19.1 · Conferir o Codex

Como humano, quero ver se o Codex está pronto para o Metri usar, para despachar trabalho para ele com segurança.

## Regras de negócio

- BR67: O Codex usa o login que a pessoa fez nele ou uma chave de API, pelo fluxo do próprio Codex. Num produto pago, o login do ChatGPT só vale com o Metri no programa "Sign in with ChatGPT" (ADR-0009).

## Critérios

- [ ] Com o Codex pronto na máquina, o teste abre uma sessão curta do harness, e a tela mostra a versão e o modo ativo.
- [ ] Com a versão diferente da suportada, a tela avisa e mostra a versão suportada.
- [ ] Os testes de contrato do driver passam com o Codex: eventos, aprovações, retomada, subagentes e a Policy traduzida.
