# T5.1 · Plano projetado a partir do git

## O que entrega

O Metri lê o plano do projeto no git (MATRIX, specs e tickets) e o projeta no banco pelos ids dos arquivos, reimportando a cada mudança. O git é a fonte do plano até a troca da S10 (ADR-0012).

## Critérios

- [ ] Ao abrir um projeto, as features, as slices e os tickets da branch padrão aparecem com os mesmos ids, e o `git status` do repositório não muda.
- [ ] O status de um ticket vem do arquivo dele na branch `ticket/<id>`, quando ela existe; senão, na branch da slice; senão, na branch padrão.
- [ ] Um commit novo numa dessas branches reimporta o plano em até 5 s, e um id que saiu dos arquivos sai da projeção.
- [ ] Um plano que não passa no docs-lint não é importado: a projeção anterior fica, e a Inbox tem o aviso com a saída.
