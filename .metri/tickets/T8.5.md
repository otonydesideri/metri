# T8.5 · Cópia fixa do Metri que conduz

## O que entrega

O roteiro e o script para o humano montar a cópia fixa do Metri que conduz (ADR-0008): uma worktree travada por `git worktree lock`, fora do repositório e da pasta de Workspaces, na tag `app-v0.1.0`, com o build feito, a pasta de dados padrão e o script de partida; a instalação do `bubblewrap` e do `socat` que o sandbox pede; e o passo de atualizar a cópia.

## Critérios

- [ ] A cópia fixa sobe pelo script de partida, com a pasta de dados padrão, e abre o navegador, e a tela de Harnesses mostra o sandbox disponível.
- [ ] A worktree da cópia está travada, e arquivar os Workspaces não a toca.
- [ ] Um merge na branch padrão do repositório não muda o servidor que roda da cópia.
- [ ] Atualizar a cópia para uma tag nova é um passo do roteiro, feito pelo humano, e o banco segue com a cópia antes das migrations.
- [ ] O humano confirma que montou a cópia pelo roteiro.
