# UC13.3 · Resolver um conflito de integração

Como humano, quero que um agente tente resolver um conflito de merge antes de ele chegar a mim, para resolver à mão só o que ele não conseguir.

## Regras de negócio

- BR60: O Run do papel `integrate` resolve o conflito de rebase e roda os checks de novo; sem solução, o conflito vira aviso na Inbox.

## Critérios

- [ ] Com conflito no rebase, um Run do papel `integrate` abre no Workspace da slice.
- [ ] Resolvido o conflito, os checks rodam de novo antes do merge.
- [ ] Sem solução, a Inbox recebe o aviso com os arquivos em conflito.
