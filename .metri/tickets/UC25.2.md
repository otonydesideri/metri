# UC25.2 · Rodar o Claude no Windows sem sandbox

Como humano, quero saber que no Windows nativo o sistema não protege a máquina dos comandos do agente, para decidir com conhecimento se aceito.

## Regras de negócio

- BR79 (sensitive): No Windows nativo, a Policy do Claude vale por aprovação e allowlist, nunca pelo sistema operacional. O Metri não liga o sandbox do SDK onde ele não existe e nunca pula as aprovações.
- BR80: O humano aceita a Policy reduzida uma vez por projeto, e o aceite fica registrado com quem e quando.

## Critérios

- [ ] No Windows nativo, a tela de Harnesses e cada Run do Claude mostram que nada é imposto pelo sistema operacional.
- [ ] O primeiro despacho de um projeto no Windows nativo pede o aceite da Policy reduzida, e sem ele nenhum Run do Claude começa.
- [ ] Um comando fora da allowlist pede aprovação, como nas outras plataformas.
- [ ] O modo de permissão do Claude nunca é o que ignora as aprovações.

## Notas

- A decisão é revista quando o Claude Code ganhar sandbox no Windows (ADR-0010).
