# UC21.2 · Mapear um repositório com código

Como humano, quero trazer para o método um repositório que já tem código, para planejar o que vem a seguir sem fingir que nada existe.

## Regras de negócio

- BR70: Num repositório com código, nada é copiado, e o mapeamento fica pendente.

## Critérios

- [ ] Num repositório com código, nenhum arquivo de código é copiado, e a Visão geral mostra o mapeamento como próximo passo.
- [ ] Com o mapeamento pendente, o Look across começa por um Run somente leitura, e o resultado aparece no portão de plano como slices feitas propostas e regras de projeto em rascunho.
