# ADR-0007 Integração entre módulos além do contrato compartilhado

status: proposed
area: backend
kind: decision

## Contexto

integração entre módulos além do contrato compartilhado (capacidade exposta dedicada, comando de um módulo sobre outro) não tem desenho fechado; até essa decisão, módulo novo não introduz mecanismo próprio de integração.
